# Perguntas frequentes

**Preciso instalar Python?** Não normalmente. Node.js e npm são necessários. Alguns módulos nativos podem exigir Python ou ferramentas de compilação.

**O npm não funciona no PowerShell.** Tente `npm.cmd -v`. Se não funcionar, repare a instalação oficial do Node.js.

**Apareceu “Ativação pendente”.** Abra a extensão e ative sua licença individual `BDS2.`, enviada pelo responsável.

**Licença e token são iguais?** Não. A licença BDS2 autoriza o uso por prazo definido; o token local permite comunicação entre extensão e motor no próprio computador.

**O campo do token ficou em branco após salvar.** Isso pode ser normal por segurança; confira o indicador de conexão.

**Erro EADDRINUSE na porta 18443.** Você provavelmente iniciou mais de um motor. Encerre a instância duplicada e mantenha apenas uma.

**Erro Cannot find package '@whiskeysockets/baileys'.** Execute `INSTALAR-MOTOR.bat` dentro do mesmo pacote em que inicia o motor, com internet.

**Não conectou o QR Code.** Confira o código mais recente no terminal, os dispositivos já vinculados e a versão do WhatsApp. Baileys é um cliente não oficial e pode perder compatibilidade.

**Uma licença pode ser copiada para outro computador?** A edição offline atual não consegue impedir tecnicamente isso. Não compartilhe seu código.

**Meu acesso venceu.** Solicite renovação ao responsável. Não é necessário reinstalar tudo.

**Posso enviar ofertas a qualquer pessoa?** Não. Use somente com autorização para publicar no grupo ou quando o contato pediu a oferta.

**Aparece “aceito pelo servidor”.** Confira no WhatsApp antes de enviar novamente para evitar duplicação.
