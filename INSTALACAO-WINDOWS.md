# Instalação no Windows — Baú da Sil Community v2.1.1

Este guia foi preparado para iniciantes. **Baixe apenas o ZIP público na área Releases**, quando estiver disponível; não baixe o Kit Mestre do administrador.

## Antes de começar
Você precisa de Windows, Google Chrome, internet, WhatsApp no celular, Node.js (22 ou superior) e npm. Você também precisa do código de ativação individual `BDS2.` enviado pelo responsável.

## 1. Verifique Node.js e npm
Instale Node.js pelo site oficial https://nodejs.org/ e abra um novo Prompt de Comando. Execute:

```bat
node -v
npm.cmd -v
```

Ambos devem exibir versões. Se não funcionar, repare a instalação e confira o PATH. Python não é requisito geral, mas certas dependências podem solicitar ferramentas adicionais.

## 2. Extraia o programa
Na página **Releases**, baixe `BauDaSil-Community-v2.1.1-PARA-DISTRIBUIR.zip`. Use **Extrair tudo** e mantenha os arquivos numa pasta definitiva, por exemplo `Documentos\BauDaSil-Community`.

## 3. Instale e inicie o motor
Na pasta extraída, execute `INSTALAR-MOTOR.bat`, aguarde terminar e depois execute `INICIAR-MOTOR.bat`. Mantenha a janela preta aberta. A mensagem **Ativação pendente** é normal antes de ativar a licença. Não divulgue o token mostrado.

## 4. Instale a extensão Chrome
Abra `chrome://extensions`, ative **Modo do desenvolvedor**, clique em **Carregar sem compactação** e escolha a pasta `Extensao-Chrome` dentro do pacote. Mantenha somente uma versão ativa.

## 5. Ative e conecte
Abra o ícone Baú da Sil no Chrome. Cole o código de licença **BDS2.** que recebeu pelo WhatsApp e clique em **Ativar licença**. Em seguida cole o **token do motor local**, exibido na janela preta, e clique em **Salvar token e verificar**. Se a interface exigir o token primeiro, faça essa etapa antes de ativar a licença. A senha administrativa do gerador **não** é usada aqui.

## 6. Vincule o WhatsApp
Quando surgir QR Code no terminal, abra no celular **Dispositivos conectados → Conectar dispositivo**. Leia o QR Code do próprio terminal. Aguarde confirmação da conexão.

## 7. Compartilhe uma oferta
Abra https://catalogo.ananeves.com.br/catalog e escolha a oferta. Use o ícone de compartilhar ao lado de **Copiar mensagem** ou, se necessário, o botão **Capturar foto + legenda desta página** no painel da extensão. Revise foto, texto, preço e link. Selecione somente grupos nos quais possa publicar e contatos que pediram a oferta. Verifique a mensagem no WhatsApp depois: **aceito pelo servidor não é confirmação de entrega**.
